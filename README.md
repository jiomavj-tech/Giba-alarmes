# Giba Alarmes – Diagnóstico de centrais

App de campo (PWA) para diagnóstico de centrais de alarme, organizado por fabricante e modelo.

- **Intelbras:** AMT 2010 / 2110 / 2018 e AMT 3010
- **Hikvision:** em breve
- **JFL:** em breve

Funções: leitura das falhas do teclado, medições com OK / Não OK, testes livres e relatório de atendimento pronto para copiar.
Funciona offline depois do primeiro acesso e pode ser instalado na tela inicial do celular.

Referências: manuais dos fabricantes, ABNT NBR 5410 e NR-10.
